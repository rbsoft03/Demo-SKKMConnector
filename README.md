# Демо приложение коннектора для Сервера ККМ

Настольное приложение (Avalonia), которое показывает возможности библиотеки
[`SkkmConnectorCSharp`](https://github.com/sodiUmU/SKKMConnector) вживую:
для каждого метода коннектора есть готовый пример — его **исходный код** видно на
экране, а **ответ сервера** приходит после нажатия «Запустить».

По сути это интерактивный справочник: слева — дерево примеров по группам API,
справа — что именно отправляем в коннектор и что получаем от Сервера ККМ.

## Что показывает

- **Все группы REST API** — примеры разложены по дереву, повторяющему структуру
  Сервера ККМ: авторизация, администрирование (ККТ, служба), кассовые смены, отчёты,
  печать чеков, коррекции (ФФД 1.2 и 1.0.5), возвраты, наличные, нефискальные чеки
  (слипы, картинки, рекламные), маркировка, фискализация, очередь, шаблоны, операции.
- **Код запроса** — в панели «Запрос» показан реальный C#-код примера: как
  заполняются свойства `ServerKkm` и какой метод вызывается (с подсветкой синтаксиса).
- **Ответ сервера** — в панели «Ответ» выводится результат вызова (JSON/поля).
- **Живой сервер** — примеры реально обращаются к Серверу ККМ по указанному адресу;

## Требования

- **.NET 6 SDK** (`net6.0`).
- **Windows** - приложение собирается как `WinExe`.
- **Запущенный Сервер ККМ** - адрес и порт службы печати (по умолчанию
  `localhost:4398`); для примеров подойдёт эмулятор ККТ.
- **Пакет `SkkmConnector`** - демо берёт его из локального фида `./packages`
  (см. [Запуск](#запуск)).

## Запуск

Приложение ссылается на NuGet-пакет `SkkmConnector` **1.25.5** и ищет его в локальной
папке `packages` рядом с проектом (`nuget.config`):

```xml
<add key="local-skkm" value="./packages" />
```

1. Положите файл `SkkmConnector.1.25.5.nupkg` в папку `SkkmNugetSample/packages`
   (если его там ещё нет - соберите пакет коннектора: `dotnet pack` в проекте
   `SkkmConnector`, см. [README коннектора](https://github.com/sodiUmU/SKKMConnector/blob/main/README.md)).
2. Восстановите зависимости и запустите:

```powershell
dotnet restore
dotnet run
```

Либо откройте проект в Visual Studio / Rider и запустите как обычно (`F5`).

3. Запустите Сервер ККМ, чтобы примерам было к чему обращаться.

## Настройка подключения

В верхней панели задаётся подключение — те же свойства, что у `ServerKkm`.
Значения по умолчанию (подсказки в полях):

| Поле | Пример | Свойство коннектора |
| --- | --- | --- |
| Хост | `localhost` | `Host` |
| Порт | `4398` | `Port` |
| Токен | `api_key` | `Token` |
| Устройство | `Emu` | `DeviceName` |
| Кассир | `Иванов А.И.` | `Cashier.Name` |
| ИНН кассира | `7722345678` | `Cashier.Vatin` |
| Id документа | — | `DocumentId` (для GET-по-id) |
| Период с / по | последние 7 дней | `ShiftsFrom` / `ShiftsTo` (для списков) |

Токен нужен, только если на сервере выключен анонимный доступ. `Ping` работает и без него.

## Как устроены примеры

Все примеры лежат в папке `Examples/` (дерево совпадает с группами API) и включены
в сборку как содержимое, чтобы приложение могло показать их исходный код.

Каждый пример — это класс-наследник `Sample`:

```csharp
public class CheckSample01 : Sample
{
    public const string GroupPath = "Работа с ККМ|Печать чеков|Примеры чеков";
    public const string Title = "Продажа (базовый чек)";

    public async Task<ServerKkm> PostCheckSample01()
    {
        kkm.DeviceName = deviceName;
        kkm.Cashier = new Cashier { Name = cashierName, Vatin = cashierVatin };
        kkm.NewRequest();
        kkm.PaymentType = CheckType.Sale;
        kkm.TaxVariant  = TaxSystem.ЕНВД;
        kkm.Positions.Add(new FiscalLine { Name = "Бутылка с водой 1л.", Price = 30m, Tax = "20" });
        kkm.Payments = new Payments { Cash = 30m };
        await kkm.PrintCheck();
        if (!kkm.Ok)
            throw new InvalidOperationException(kkm.ErrorDescription);
        return kkm;
    }
}
```

- **`GroupPath`** — путь в дереве слева (разделитель `|`), повторяет группу API.
- **`Title`** — название примера в дереве.
- **Метод** — заполняет свойства `ServerKkm` (`kkm`) и вызывает метод коннектора;
  подключение, подставляется из панели настроек.

Именно текст этого файла отображается в панели «Запрос», а `kkm` после вызова —
в панели «Ответ».

## Добавить свой пример

1. Создайте класс-наследник `Sample` в подходящей папке внутри `Examples/`.
2. Задайте `GroupPath` (где показать в дереве) и `Title` (как назвать).
3. В методе заполните свойства `kkm` и вызовите нужный метод коннектора.
4. Пересоберите — пример появится в дереве.

Полное описание всех методов, полей и типов - в
[документации API коннектора](https://github.com/sodiUmU/SKKMConnector/blob/main/API.md).
